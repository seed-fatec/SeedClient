# Vue 3 + Vite

Este projeto é um template inicial para desenvolver aplicações com Vue 3 e Vite. Ele utiliza SFCs Vue 3 `<script setup>`. Confira a [documentação do script setup](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) para saber mais.

## Instalação

1. Clone o repositório:
    ```bash
    git clone https://github.com/seed-fatec/SeedClient.git
    ```
2. Navegue até o diretório do projeto:
    ```bash
    cd SeedClient
    ```
3. Instale as dependências:
    ```bash
    npm install
    ```

## Executando o Servidor de Desenvolvimento

Inicie o servidor de desenvolvimento com o seguinte comando:
```bash
npm run dev
```
A aplicação estará disponível em `http://localhost:5173` por padrão.

## Construindo para Produção

Para construir o projeto para produção, execute:
```bash
npm run build
```
Os arquivos construídos estarão localizados no diretório `dist`.

## Visualizando a Build de Produção

Para visualizar a build de produção localmente, use:
```bash
npm run preview
```
